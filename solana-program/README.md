# MonQuest Anchor Program (`solana-program/`)

An example **Anchor (Rust)** program — a simple permissioned counter — plus its
client-side IDL walkthrough.

```
solana-program/
├── Anchor.toml
├── programs/monquest-counter/   # Rust program (anchor-lang 0.30)
│   ├── Cargo.toml
│   └── src/lib.rs
├── app/monquest_counter.ts      # Client-side IDL usage (node)
├── migrations/deploy.ts         # anchor migrate bootstrap
├── tests/counter.ts             # mocha test (anchor test)
└── target/                      # generated by `anchor build` (gitignored)
```

## Why Anchor and when to use it

Anchor is the standard framework for Solana programs: it generates the IDL
that drives our TypeScript client (`app/monquest_counter.ts`), handles PDA
seeds/CPIs, and enforces account constraints at the framework level. We ship a
complete Anchor project so the program can be built, tested, and extended the
canonical way.

**Justification for the native `web3.js` fallback in the app services:**

Building/deploying the Anchor program requires the Rust toolchain (`cargo`,
`solana-cli`, `cargo-build-sbf`) *and* a running local validator or a devnet
deployment. That toolchain is not available in every CI/dev box, so the runtime
features of the app (`app/lib/blockchain/solana.ts`) are deliberately built on
plain **`@solana/web3.js` + `@solana/spl-token`** — connection, SOL/SPL
balances, transfers, and token-account management all work with zero Rust. The
Anchor program is consumed through its IDL by `app/monquest_counter.ts`,
keeping the two worlds cleanly separated:

| Capability                        | Module                              | Requires Rust? |
|-----------------------------------|-------------------------------------|----------------|
| SOL balance, SPL balances         | `app/lib/blockchain/solana.ts`      | no             |
| SOL transfer (wallet & keypair)   | `app/lib/blockchain/solana.ts`      | no             |
| Anchor program interaction (IDL)  | `solana-program/app/monquest_counter.ts` | yes (build) |

## Prerequisites (Rust toolchain)

```bash
# macOS
curl -sSf https://sh.rustup.rs | sh
# Solana CLI (includes solana-test-validator)
sh -c "$(curl -sSfL https://release.solana.com/v1.18.26/install)"
# Anchor CLI
cargo install --git https://github.com/coral-xyz/anchor avm --locked --force
avm install 0.30.1
avm use 0.30.1
```

## Setup

```bash
cd solana-program
npm install

# funding / local keypair for the provider wallet
solana-keygen new -o wallet.json
solana config set --url http://127.0.0.1:8899   # or devnet
solana airdrop 10                               # localnet/devnet only
```

## Build, test, deploy

```bash
npm run build        # anchor build   → produces target/idl/monquest_counter.json
npm test             # anchor test    → runs tests/counter.ts against local validator
npm run deploy       # anchor deploy  → deploys to the cluster in Anchor.toml
npm run client       # runs app/monquest_counter.ts (initialize → increment ×3 → read)
```

## Instructions

| Instruction  | Accounts                          | Behaviour                                |
|--------------|-----------------------------------|------------------------------------------|
| `initialize` | counter(PDA), authority, system   | sets `counter.authority = signer`, count 0 |
| `increment`  | counter(PDA), authority(has_one)  | `count += 1` (authority only)            |

## .env

Copy `solana-program/.env.example` → `.env` if you run `app/monquest_counter.ts`
with a keypair from the environment. The same `SOLANA_PRIVATE_KEY` base58 secret
feeds `scripts/demo-solana.ts` at the repo root.
